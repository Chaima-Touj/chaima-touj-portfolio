REINE NOISETTE — SITE VITRINE

1) Décompressez tout le dossier.
2) Ouvrez index.html dans Chrome, Edge ou Firefox.
3) Gardez le dossier reine-noisette à côté de index.html : il contient les 45 photos originales et le logo officiel.

Pour publier le site, téléversez index.html et le dossier reine-noisette sur votre hébergement en conservant exactement cette structure.
Le site est un site vitrine : aucun panier ni validation de commande. Les créations s’affichent avec leurs détails et le contact se fait via Facebook.
